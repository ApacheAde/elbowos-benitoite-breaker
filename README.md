# Benitoite Breaker

Full-colour Python 3 neon brick-breaker arcade for [ElbowOS](https://x.com/ElbowOS).

Slide a cobalt paddle under a gold orb. Shatter seven rows of cyan / cobalt / ice / magenta / lime / amber / gold bricks. Top rows take two hits. Clear a board and the field respawns faster.

Left / Right (or A / D) slide. R resets.

## Play

```
pip install -r requirements.txt
python3 benitoite_breaker.py --play
```

## Record a 9:16 reel

```
python3 benitoite_breaker.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
